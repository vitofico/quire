# README screenshots

Captured on 2026-10-28 from the local Android development checkout based on
`5ed3839`, including its pending appearance changes. The library frames are losslessly encoded as WebP with identical decoded pixels;
the remaining frames are unaltered PNG captures. Android screenshot demo mode standardizes
the clock and hides notification icons.
The books were copied read-only from the owner's CWA library storage and imported
through Quire's ordinary EPUB file picker on a disposable emulator. This did
not change a production book, credential or account. No EPUBs or private
connection details are included in the documentation assets.

- `readme-library-sage.webp`: actual imported covers, Sage and Artwork.
- `readme-library-midnight.webp`: the same library, Midnight and Plain.
- `readme-reader.png`: an actual Sherlock Holmes page after reopening the book,
  using Sepia, Literata and full-screen reading.
- `readme-reader-preferences.png`: the reader's independent page/font controls.

The capture verifies EPUB import, cover/metadata extraction, opening and turning
pages, saved reading position, app palettes/backgrounds and reader preferences.
These offline imports do not verify OPDS authentication, a catalog download or
reading-state synchronization. All selected frames were visually inspected.
Screenshots describe the current development checkout, not a release or deployment.
